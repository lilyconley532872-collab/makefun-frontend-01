A fast, read-only make.fun frontend: the bounties board, a bounty detail page, the leaderboard, and entrant profiles. Static, no build step, verified against the live public API.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. `main.ts` regenerates the three screenshots and the dossier from the live API (`mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`).
